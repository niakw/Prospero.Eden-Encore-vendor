# Accessibility and support — vendored source repository

This repository supplies source code and dependency snapshots to the **Eden Encore** engine; it has no separate consumer application or accessibility settings.

For the controller-driven launcher, larger text, higher contrast, reduced motion, navigation, translation and limitations, use the [engine accessibility guide](https://github.com/niakw/ProsperoEden-Encore/blob/main/ACCESSIBILITY.md) and the [language directory](https://github.com/niakw/ProsperoEden-Encore/blob/main/LANGUAGES.md).

For accessibility defects affecting the maintained dependency code, [open an issue in the engine repository](https://github.com/niakw/ProsperoEden-Encore/issues), noting the affected task, exact engine/vendor revisions and a reproducible example. Screenshots are optional. Do **not** publish keys, saves, private firmware or proprietary model files.

No blanket WCAG conformance or native console compatibility claim is made here.
