# Null TIC shader environment — source candidate
Upstream: https://github.com/zortos293/Lichii/pull/1443 (merged, Windows/NVIDIA report; not FC27 proof). Maintained owner preimage 787cbe84d2a4d587d944f980195932e83979a479. The PS5-selected format-19 reader previously classified every all-zero TIC as 1D. The candidate maps only exactly zero descriptors to normalized RGBA8 2D, leaves real descriptors alone, and adds a reserved CBUF sentinel to preserve explicitly recorded 1D entries in new records. Old ambiguous 1D entries and their paired pixel formats are omitted during replay; the existing missing-value path must regenerate them on use. No format-wide deletion or version change. Old pixel-format-only records and complete warm-cache replay remain unqualified. Host witness compiles the exact selected functions using the pinned TIC header with memory/logging boundaries stubbed, and checks marker placement in the real source. The map harness uses std::unordered_map; actual production Boost map and full selected TU must pass engine CI before repinning. No hardware, game, FPS or source-build claim.
