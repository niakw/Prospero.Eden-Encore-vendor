Confirmed source risk: the native per-title reader checked only the outer header before a file-sized vector allocation; neither the actual driver header nor a staging limit was checked. The driver-specific payload is optional acceleration, separate from the guest shader environment records. Validate header size, version, vendor/device IDs and UUID before allocating it. Reject oversized payload or allocation failure with a fresh Vulkan driver cache; maintain the environment cache, existing atomically staged save and original desktop branch. Proposed conservative 512 MiB transient staging cap, not a measured runtime optimum; matching save-side bound preserves old file instead of repeatedly writing a blob larger than the read cap. No change to in-memory cache capacity, shader keys or prewarm. No new deletion on mismatched driver identity or oversize; later successful normal save may replace the stale file. Scope excludes separate Device::LoadStaticPipelineCache implementation; inspect its exact native selection independently.
